Интервалы ΔF1 включают ноль; интервалы ΔROC-AUC ноль не включают. Текстовый bootstrap может недооценивать неопределённость при кластерной зависимости по источнику.

## 7. Итог

LSTM имеет наибольший наблюдаемый F1, но bootstrap не даёт достаточных оснований утверждать о стабильном преимуществе по F1. ROC-AUC LSTM выше у рассмотренных сравнений в рамках использованного bootstrap.
